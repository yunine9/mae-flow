纪律与 build 相同:systematic-debugging(先复现读全报错定位根因再动手)、Ponytail the ladder 常驻;

修复中发现某条意见实际涉及行为/规格变更 → 停下告知用户,该条改标「转规格轮次(已确认)」,本轮不修。

全部修完 → 展示"意见 # → commit → 改动摘要"对照表,结束回复等用户确认 → done --ack(校验最新 commit 格式)。
