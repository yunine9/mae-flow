规格定稿 = 把本次变更的规格条目合入基准规格,**定稿后不可回退**(此后要改,走新的交付轮次)。
先向用户展示:验证结果摘要 + 将定稿的规格内容清单(公司语言,按话术纪律不说 archive/openspec 之类的词)。
然后用 AskUserQuestion 确认,选项:
确认定稿 / 暂不定稿(保持现状,后续再说) / 需要调整(说明哪里不对)。
(工具不可用才纯文本结束回复等确认。)
仅"确认定稿"可 done --ack "用户选择原文";其余选择按用户意图处理(暂不定稿则等用户后续指示)。
done 默认硬校验:本步内必须发生过**真实的 AskUserQuestion 提问**(harness 令牌)——
自行改写、口头声称已确认均无效。宿主未回传 AskUserQuestion 令牌时,必须让用户用纯文本明确再确认一次,
然后按 done 报错给出的 `accept-risk askuser` 单令牌兜底;禁止用 goto 跳过整个定稿确认步骤。
